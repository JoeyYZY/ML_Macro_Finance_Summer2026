# Maliar Hands-on Tutorial - Student Materials

This folder contains the English materials for Day 1 Tutorial 1:

```text
Getting Started with TensorFlow / PyTorch / JAX and Hands-on Practice
```

The main classroom track is TensorFlow, because the two reference codes used in the tutorial are TensorFlow-based. PyTorch and JAX are optional comparisons only.

## Start Here

Please begin with `01_Setup_and_Run_Guide.md`.

Before the tutorial, your minimum goal is:

1. Install a local Python/Jupyter environment.
2. Open `02_TensorFlow_Minimal_Intro.ipynb`.
3. Run the first environment-check cell successfully.

You may use AI tools to help with installation and interpret command-line error messages. If the environment still does not work, save the error message and ask TA Peiyuan Zhang during a break. During class, if your own laptop is not ready yet, follow the instructor's projected demonstration first and continue troubleshooting afterward.

## Files

| File | Purpose |

## Suggested Order

1. Follow `01_Setup_and_Run_Guide.md` and complete the environment check.
2. Run the first sections of `02_TensorFlow_Minimal_Intro.ipynb`.
3. In class, follow the instructor through `03_MMW_Growth_Model_Walkthrough.ipynb`.
4. Then follow the instructor through `04_KS_Model_Walkthrough.ipynb`.
5. Use `05_KS_Model_Full_Version.ipynb` after class if you want the full original Krusell-Smith run and precomputed outputs.

Students do not need PyTorch, JAX, GPU/CUDA, or full model training to complete the main classroom workflow.
